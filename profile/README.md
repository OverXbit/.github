# OVERXBIT

Bitcoin mining and trading for clients who want a defined investment period, clear reporting, and a private portal.

The public site is [overxbit.com](https://overxbit.com). Clients sign in there. Staff and the API live at [portal.overxbit.com](https://portal.overxbit.com).

Mining and trading are separate. A client holds contracts, each month closes as its own period, and earnings are either stored on the platform or cashed out. Withdrawing capital is a separate record from those earnings.

OVERXBIT was built to simplify high-value decisions in complex markets, with strategy that can be executed and reporting the client can read.
